# STM32 循迹竞速小车（基础版本 · 元素未开启）

基于 **STM32F103C8**（Cortex-M3）的五路循迹竞速小车工程，用于**校内比赛**。

## 硬件平台

| 项 | 说明 |
|---|---|
| 主控 | STM32F103C8（Cortex-M3，64 KB Flash / 20 KB SRAM，12 MHz 晶振） |
| 循迹传感器 | 5 路数字量灰度/红外阵列（`L2 / L1 / M / R1 / R2`），支持白底黑线、黑底白线、蓝底白线切换 |
| 姿态 | MPU6050（I²C，加速度计 + 陀螺仪） |
| 电机 | 双直流电机 + PWM 驱动，编码器测速 |
| 交互 | OLED 显示 + 按键菜单 + 串口调参输出 |

## 功能模块

| 模块 | 文件 | 说明 |
|---|---|---|
| 循迹控制 | `Control/pid.c` | 5 路传感器偏差解算 → PD 转向环 + 差速环；积分限幅（`INTEGRAL_MAX`）与 PWM 上限（`Max_PWM`）保护 |
| 速度环 | `Control/pid.c`、`Hardware/Encoder.c` | 编码器测速闭环 |
| 姿态解算 | `Hardware/kalman.c` | 卡尔曼滤波融合加速度计与陀螺仪，输出 pitch |
| 赛道元素 | `Control/element.c` | 环岛、十字、拐角、无迹线、掉头、停车等状态机（**本版本未启用**） |
| 人机交互 | `Control/menu.c`、`Hardware/OLED.c`、`Hardware/Key.c` | OLED 菜单、按键（定时器非阻塞扫描） |
| 调参 | `User/main.c`、`Hardware/Serial.c` | 串口实时输出偏差 / 输出量，用于现场整定 PID |

主循环：`main()` 负责初始化与菜单/显示；**固定周期控制全部在 `TIM2_IRQHandler` 中断里调用 `Control()`**，保证控制周期稳定。

## 目录结构

```
Control/     循迹与 PID 控制、赛道元素状态机、OLED 菜单
Hardware/    传感器、电机、编码器、MPU6050、OLED、按键、串口、卡尔曼滤波
System/      延时、定时器、系统工具
User/        main.c（入口与中断）、stm32f10x_it.c
Start/       启动文件与 CMSIS
Library/     STM32 标准外设库（ST 官方，随工程提供以便直接编译）
Objects/     编译产物（已在 .gitignore 中忽略）
```

## 编译与烧录

- IDE：**Keil MDK**，工程文件 `Project.uvprojx`（器件 STM32F103C8）
- 依赖：`Library/` 已随仓库提供，无需额外安装标准外设库
- 源码编码为 **GBK**（Keil 默认），用 UTF-8 打开中文注释会乱码，请在编辑器里按 GBK 打开

## 与原工程的差异

本仓库在原作者工程基础上修改适配，主要差异：

- 本版本**关闭赛道元素状态机**（目录名「基础版本（元素未开启）」），仅保留基础循迹逻辑
- 循迹 PD 与差速参数按本车机械特性重新整定
- 串口调参输出内容按现场调试需要调整

> 说明：具体改动以代码为准；`User/test.c` 为调试过程中的历史片段，未参与编译。
